xremap is a fast, cross-platform key remapper for Linux. Written in Rust, it works with both X11 and Wayland and supports powerful features like application-specific remapping, key sequences, multi-purpose keys, and virtual modifiers — all defined in a simple YAML configuration file.

## Why xremap?

<CardGroup cols={3}>
  <Card title="Cross-platform" icon="display">
    Works on X11 and all major Wayland compositors — GNOME, KDE, Hyprland, Sway, Niri, COSMIC, and Pantheon.
  </Card>
  <Card title="App-specific" icon="window">
    Apply different remappings per application or window title using `application` and `window` filters.
  </Card>
  <Card title="Key sequences" icon="keyboard">
    Remap multi-key sequences like Emacs-style `C-x C-c` to any action.
  </Card>
  <Card title="Multi-purpose keys" icon="toggle-on">
    Make a key act differently when tapped versus held — turn CapsLock into both Esc and Ctrl.
  </Card>
  <Card title="Virtual modifiers" icon="layer-group">
    Designate any key as a modifier without changing its base behavior.
  </Card>
  <Card title="Scriptable" icon="code">
    Extend xremap with custom Rust plugins for logic that config YAML cannot express.
  </Card>
</CardGroup>

## Get up and running

<Steps>
  <Step title="Install xremap">
    Download a binary from the [releases page](https://github.com/xremap/xremap/releases) or install via your distro's package manager. See [Installation](/installation) for all options.
  </Step>
  <Step title="Set up permissions">
    Run with `sudo`, or add your user to the `input` group for passwordless operation. See [Running without sudo](/running/without-sudo).
  </Step>
  <Step title="Write a config file">
    Create a `config.yml` with `modmap` and `keymap` sections. See the [Quickstart](/quickstart) for a complete working example.
  </Step>
  <Step title="Start remapping">
    Run `xremap config.yml` (or `sudo xremap config.yml`) and your remappings take effect immediately.
  </Step>
</Steps>
